# 해드리오 사이트 빌드

사이트는 정적 HTML입니다. 문구와 가격은 `src/`에서 고치고, 빌드하면 각 언어 페이지가 다시 만들어집니다.

## 파일 구조

| 위치 | 내용 |
| --- | --- |
| `src/site.json` | 가격(원), 연락처, 사업자 정보, 언어 목록, 문의 폼 설정 |
| `src/i18n/en.json` | 영어 문구 (기준 파일) |
| `src/i18n/ja.json` 외 4개 | 일본어, 简体中文(zh-cn), 繁體中文(zh-tw), 베트남어(vi), 태국어(th) |
| `tools/` | 빌드 스크립트 (의존성 없음, Node 18 이상) |
| `assets/` | CSS, JS, 폰트, 도장 로고, 공유 이미지 |

`index.html`, `*/index.html`, `404.html`, `sitemap.xml`은 빌드 결과물입니다. 직접 고치지 마세요.

## 고치는 순서

1. 문구: `src/i18n/en.json`과 같은 위치의 각 언어 파일을 함께 고칩니다.
2. 가격: `src/site.json`의 `services[].won`을 고치고, 문구 안의 `{won:56000}` 같은 금액도 맞춥니다.
3. 번역 확인: `node tools/check-i18n.mjs ja` (언어마다 실행)
4. 빌드: `node tools/build.mjs`
5. 바뀐 파일을 모두 커밋합니다. main에 올라가면 Vercel이 바로 배포합니다.

## 규칙

- 문구 속 `{price}`, `{won:39000}` 같은 자리 표시는 지우거나 바꾸지 않습니다. 빌드가 이 부분을 채웁니다.
- 원화는 `{won:금액}`으로 씁니다. 언어별 표기(베트남어는 `39.000 ₩`)는 빌드가 처리합니다.
- 번역 파일의 키와 목록 개수는 영어와 같아야 합니다. 다르면 빌드가 멈추고 위치를 알려 줍니다.

## 견적서·인보이스

- 관리자 화면 `__admin__/documents.html`에서 만듭니다. 관리 홈(`__admin__/`)에도 링크가 있고, 로그인은 기존 관리자 계정을 씁니다.
- 처음 한 번 Supabase SQL 편집기에서 `supabase/sql/billing_docs.sql`을 실행합니다. 실행하기 전에는 각자 브라우저에만 저장됩니다. 다시 실행해도 됩니다.
- '기본정보 설정'에 넣어 둔 값이 새 문서에 자동으로 채워집니다: 발행인 정보(한국어·영어), 우리 담당자, 결제기한·유효기한 일수, 입금 계좌, 송금 수수료(OUR). 입금 계좌는 관리자만 읽는 DB에만 저장하고, 저장소가 공개라서 코드와 SQL 파일에는 넣지 않습니다.
- 순서: ① 내용 입력 → ② 한국어·English 미리보기를 각각 보고 체크 → ③ '발행하기' → 언어별 'PDF 저장'. 미리보기는 입력하는 대로 바뀌고, 내용을 고치면 체크가 풀려서 다시 확인해야 합니다. 발행해도 고객에게 메일은 가지 않습니다.
- 청구 대상: 개인이면 고객 이름, 회사면 회사명과 담당자(문서에는 Attn:)를 넣습니다. 비어 있는 칸은 문서에 나오지 않고, 고르지 않은 유형의 이름은 출력되지 않습니다.
- 품목: '추가할 품목'에서 고른 뒤 '품목 추가'. 컨시어지 서비스(일수), 공항 픽업·공항 샌딩(횟수), 공항 픽업 및 샌딩(묶음 1개 = 한 줄), 직접 입력이 있습니다. 품목명·단위·세부사항은 언어마다 직접 고칠 수 있고, 금액은 수량 × 단가입니다. 품목에는 기본 단가가 없습니다. 새 품목 종류는 페이지 코드의 `SERVICES`에 한 줄 추가합니다.
- 세부사항(날짜, 시간, 항공편 시각 등)은 그 품목 아래에만 나옵니다. 특이사항은 선택이고, 비워 두면 제목까지 문서에 나오지 않습니다.
- 번호는 `Q-연도-0001`, `INV-연도-0001` 형식으로 다음 번호가 자동으로 들어가고, 초안일 때는 고칠 수 있습니다. 발행하면 고정됩니다. 한국어·영어 문서는 같은 번호를 씁니다.
- 인보이스의 입금 정보: 은행, 예금주, 계좌번호, SWIFT/BIC, 송금 수수료, 송금 참조(= 인보이스 번호). 발행한 문서는 발행한 날의 발행인·입금 정보를 그대로 간직합니다.
- 'PDF 저장'을 누르면 인쇄 창이 열립니다. 대상은 'PDF로 저장', 머리글과 바닥글은 끕니다. 파일 이름 끝에 `_KR`, `_EN`이 붙습니다.
- 견적서에서 '인보이스로 만들기'를 누르면 같은 내용으로 인보이스 초안이 생깁니다. 선택 품목은 빠집니다.
- 초안만 삭제할 수 있습니다. 발행한 문서는 상태를 '무효'로 바꿉니다.
- 'JSON 내보내기·가져오기'로 문서 내용을 파일로 옮길 수 있습니다. 입금 계좌는 파일에 들어가지 않습니다.

## 문의 폼

- 요청은 Supabase Edge Function `submit-inquiry`로 갑니다 (`is_secret: true`). 관리자 화면 `__admin__/`에서 확인합니다.
- 스팸 방지는 Cloudflare Turnstile입니다. 새 도메인(예: Vercel 미리보기 주소)에서 폼을 시험하려면 Cloudflare 대시보드의 Turnstile 위젯 설정에 그 도메인을 추가해야 합니다.
